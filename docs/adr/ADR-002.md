# ADR-002: Opt-in Liquibase seed data

Status: Accepted | Date: 2026-11-17 | Supersedes: None

## Context

The schema must always be migrated for Hibernate validation, while initial courts and surfaces should be optional. Disabling Liquibase entirely would prevent startup on an empty database; startup code would duplicate migration tracking. The class diagram assigns each court one surface, and BET-001 requires unique active names and numbers and CZK-per-minute prices.

## Decision

Use a separate Liquibase seed changeset, controlled by `SEED_DATA_ENABLED` (default `false`) through a Liquibase changelog parameter. A changeset-level SQL precondition checks the parameter and uses `onFail: CONTINUE`, leaving the changeset pending and absent from `DATABASECHANGELOG` when disabled; errors halt startup. Keep the schema changeset unconditional and retain Hibernate validation. On first enabled startup, insert Clay at 3.60 CZK/minute and Hard at 5.00 CZK/minute, assigning courts 1 and 2 to Clay and 3 and 4 to Hard. Use generated IDs, valid timestamps, and normalized active keys. Run inserts transactionally on H2: conflicts with active seed names or court numbers fail without changing existing data, leaving partial seed rows and successful tracking absent. Soft-deleted names and numbers remain reusable. Record the changeset only after success.

## Consequences

Disabling seeding does not remove existing data; an in-memory database starts fresh when recreated. Conflicts must be resolved before retrying. Integration tests cover absent and false settings, exact counts, prices, assignments, active keys and timestamps, pending and successful changelog tracking, delayed enabling, repeated startup, disabling after seeding, and reuse of soft-deleted keys. Test both active-name and active-number conflicts, including a late failure, rollback, unchanged existing data, absent tracking, and successful retry. End-to-end tests exercise startup and observable seeded and empty results. Document configuration and run `./mvnw clean verify` with Java 25.
