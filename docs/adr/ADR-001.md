# ADR-001: Temporarily disable Spring Security

Status: Accepted | Date: 2026-11-16 | Supersedes: None

## Context

Court and surface APIs need to be usable, but authentication and authorization are outside this increment. Spring Security is currently a dependency with no custom configuration, so its defaults secure requests and apply CSRF protection. The use-case diagram assigns management to admins, but that access control is not yet implemented. Alternatives are to retain the defaults or configure explicit unauthenticated access.

## Decision

Temporarily comment out the Spring Security runtime and test dependencies, with a clear reminder to restore and configure security. This follows the requested temporary approach without introducing an incomplete authentication design.

## Consequences

The application and management endpoints will be unauthenticated and unauthorized. They must not be exposed to untrusted users until appropriate security is implemented. Restoring dependencies alone is not sufficient: authentication, authorization, and their tests still need design and implementation.
